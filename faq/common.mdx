## General

<Accordion title="Is Wraith free?">
  Yes. No premium tiers.
</Accordion>

<Accordion title="Slash commands?">
  Yes — most commands support both `,help` and `/help`.
</Accordion>

## Prefixes

<Accordion title="Default prefix / change it">
  Default is `,`. Change: `,prefix set <prefix>` · Reset: `,prefix reset`
</Accordion>

<Accordion title="Personal prefix across servers">
  `,selfprefix <prefix>` — overrides server prefix for you.
</Accordion>

<Accordion title="Forgot the prefix">
  `@Wraith prefix` or `@Wraith help` always work.
</Accordion>

## Last.fm

<Accordion title="Link / unlink">
  Link: `,lastfm set <username>` · Unlink: `,lastfm unset`
</Accordion>

## Jail

<Accordion title="Setup">
  `,jail setup` (auto) — or `,jail role` \+ `,jail channel` (manual, configure overwrites yourself).
</Accordion>

<Accordion title="Re-jail not working on rejoin">
  Jail role was deleted, or Wraith's role is below it.
</Accordion>

## Levels

<Accordion title="Send level-ups to a specific channel">
  `,levels messagemode #channel`. Other modes: `context`, `pm`, `none`.
</Accordion>

<Accordion title="Role rewards">
  `,levels addreward 10 @Role` · `,levels sync` to retroactively assign.
</Accordion>

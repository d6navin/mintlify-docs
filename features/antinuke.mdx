Detects coordinated destructive actions and punishes the offender automatically.

<Warning>
  Requires **Administrator** to configure. Wraith's role must sit **above** any role it needs to punish.
</Warning>

---

## Enable and disable

```text
,antinuke enable
,antinuke disable
```

Enabling activates all modules with default settings.

---

## Modules

| Module | What it watches |
| --- | --- |
| `ban` | Members being banned from the server. |
| `kick` | Members being kicked from the server. |
| `role_delete` | Server roles being deleted. |
| `channel_delete` | Channels being deleted. |
| `webhook_create` | Webhooks being created in channels. |
| `bot_add` | Bots being added (authorized) to the server. |

---

## Thresholds

`--threshold` = action count · `--duration` = window in seconds.

```text
,antinuke ban on --threshold 3 --duration 10
,antinuke channel_delete on --threshold 2 --duration 5
,antinuke role_delete on --threshold 2 --duration 5
,antinuke webhook_create on --threshold 5 --duration 15
,antinuke bot_add on --threshold 1 --duration 30
```

Tighter thresholds for destructive actions (`channel_delete`, `role_delete`); looser for legitimate bulk actions (`ban`).

---

## Punishments

Set per-module via `--punishment`:

```text
,antinuke ban on --threshold 3 --duration 10 --punishment stripstaff
```

| Punishment | What it does |
| --- | --- |
| `stripstaff`_(default)_ | Removes all elevated roles from the offending user, stripping their moderation capabilities without banning them. |
| `ban` | Permanently bans the offending user from the server. |
| `kick` | Kicks the offending user from the server. |

Default is `stripstaff` — conservative, preserves investigation options.

---

## Command enforcement

By default antinuke watches Discord-side actions. Add `--command` to also enforce thresholds against Wraith's own commands (`,ban`, `,channel delete`, etc.).

```text
,antinuke ban on --threshold 3 --duration 10 --command
,antinuke channel on --threshold 2 --duration 5 --command
```

---

## Whitelist

Whitelisted users bypass all checks.

```text
,antinuke whitelist add @user
,antinuke whitelist remove @user
,antinuke whitelist list
```

<Warning>
  Whitelisted users can perform mass destructive actions unchecked. Reserve for co-owners with 2FA.
</Warning>

---

## Admins

Users who can modify antinuke config without being owner.

```text
,antinuke admin add @user
,antinuke admin remove @user
```

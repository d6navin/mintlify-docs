Collaborative counting channel. Wraith enforces the rules.

## Setup

```text
,counting channel #counting
,counting enable
```

## Commands

| Command | Description |
| --- | --- |
| `,counting channel #channel` | Set the channel Wraith monitors for counting. |
| `,counting enable` | Enable counting in the configured channel. |
| `,counting disable` | Pause counting without clearing the current count or settings. |
| `,counting reset` | Reset the count back to 0. |
| `,counting current` | Display the current count. |

## Rules

- Members must alternate — no counting twice in a row
- Wrong number resets the count to 0
- Non-number messages are deleted

<Warning>
  Requires **Manage Messages** in the counting channel.
</Warning>

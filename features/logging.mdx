Route server events to log channels with per-event colors and filters.

## Setup

```text
,logs channel #mod-logs    # register
,logs                       # view config
,logs remove #mod-logs      # deregister
```

<Warning>
  Wraith uses webhooks. Requires **Manage Webhooks**, **Send Messages**, and **Embed Links** in each log channel.
</Warning>

Each event can be routed to a different channel.

---

## Events

| Event | Triggers when… |
| --- | --- |
| `message_delete` | A message is deleted in any channel |
| `message_edit` | A message is edited in any channel |
| `member_join` | A user joins the server |
| `member_leave` | A user leaves or is removed from the server |
| `member_ban` | A user is banned from the server |
| `member_unban` | A user's ban is revoked |
| `member_kick` | A user is kicked from the server |
| `role_create` | A new role is created |
| `role_delete` | A role is deleted |
| `role_update` | A role's name, color, or permissions are changed |
| `channel_create` | A new channel or category is created |
| `channel_delete` | A channel or category is deleted |
| `nickname_update` | A member's server nickname is changed |

No retroactive logging. `message_delete` attribution requires **View Audit Log**.

---

## Adding and removing events

<CodeGroup>

```text Subscribe to an event
,log add #mod-logs message_delete
```

```text Unsubscribe from an event
,log remove #mod-logs message_delete
```

</CodeGroup>

---

## Custom colors

Per-event, per-channel hex colors.

<CodeGroup>

```text Set a color
,log color set #mod-logs message_delete #ff0000
```

```text Remove a color
,log color remove #mod-logs message_delete
```

```text List all colors for a channel
,log color list #mod-logs
```

</CodeGroup>

---

## Ignoring members and channels

<CodeGroup>

```text Ignore a member
,log ignore @user
```

```text Ignore a channel
,log ignore #channel
```

```text View the ignore list
,log ignore list
```

</CodeGroup>

Ignoring a channel suppresses all events from it. Ignoring a member suppresses events where they're the actor.

## Troubleshooting

<Accordion title="Logs stopped appearing">
  The webhook was likely deleted. Re-run `,logs channel #your-channel` to recreate it.
</Accordion>

<Accordion title="No 'deleted by' info on message deletions">
  Grant Wraith **View Audit Log** at the server level.
</Accordion>

<Accordion title="No logs at all">
  1. `,logs` to confirm registration
  2. Verify Send Messages, Embed Links, Manage Webhooks
  3. Subscribe an event with `,log add`
  4. Check `,log ignore list`
</Accordion>

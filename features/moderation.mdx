Full moderation toolkit — bans, mutes, jails, role management, lockdowns, and custom punishment messages.

## Basic Commands

All actions are logged and support [duration syntax](#duration-syntax) where applicable.

| Command | Description |
| --- | --- |
| `,ban <user> [reason]` | Permanently ban a member from the server. |
| `,unban <user>` | Revoke an existing ban. |
| `,softban <user> [reason]` | Ban then immediately unban, deleting recent messages without keeping the ban. |
| `,hardban <user> [reason]` | Permanently ban a user and automatically re-ban them if anyone unbans them. |
| `,tempban <user> <duration> [reason]` | Ban a member for a set duration, then automatically unban them. |
| `,kick <user> [reason]` | Remove a member from the server (they can rejoin). |
| `,mute <user> [duration] [reason]` | Mute a member, preventing them from sending messages. |
| `,unmute <user>` | Remove a mute from a member. |
| `,warn <user> <reason>` | Issue a formal warning to a member. |
| `,warnings <user>` | View the warning history for a member. |
| `,delwarn <warn_id>` | Delete a single warning by its ID. |
| `,clearwarns <user>` | Remove all warnings from a member. |

<Warning>
  `,hardban` is permanent — any unban is auto-reversed by Wraith.
</Warning>

## Jail

Isolates a member with a restricted role \+ dedicated channel. Re-applies on rejoin.

| Command | Description |
| --- | --- |
| `,jail <user> [reason]` | Jail a member, restricting them to the jail channel. |
| `,unjail <user>` | Release a member from jail and restore normal access. |
| `,jail setup` | Automatically create the jail role and channel with the correct permissions. |
| `,jail role <role>` | Manually assign an existing role as the jail role. |
| `,jail channel <channel>` | Manually assign an existing channel as the jail channel. |
| `,jail reset` | Remove the current jail configuration. |

<Warning>
  Manual setup via `,jail role` / `,jail channel` requires you to configure channel overwrites yourself — deny **View Channel** on all non-jail channels.
</Warning>

## Channel Tools

| Command | Description |
| --- | --- |
| `,slowmode <seconds>` | Set a slowmode delay (in seconds) on the current channel. Use `0` to disable. |
| `,purge <amount> [filter]` | Bulk-delete up to a specified number of messages in the current channel. |
| `,lock [channel]` | Prevent members from sending messages in a channel. |
| `,unlock [channel]` | Re-enable messaging in a locked channel. |
| `,lockdown` | Lock every channel in the server simultaneously. |
| `,lockdown end` | Unlock all channels and restore normal server access. |

`,lockdown` has a 10s cooldown.

## Nickname Tools

| Command | Description |

| `,nick <user> <nickname>` | Change a member's nickname. |
| `,forcenick <user> <nickname>` | Lock a member's nickname so they cannot change it themselves. |

## Role Management

### Add & Remove

| Command | Description |
| --- | --- |
| `,role add <@role> [@user]` | Add a role to a user, or to yourself if no user is specified. |
| `,role remove <@role> [@user]` | Remove a role from a user, or from yourself. |
| `,role add humans <@role>` | Add a role to every non-bot member in the server. |
| `,role remove humans <@role>` | Remove a role from every non-bot member. |
| `,role add bots <@role>` | Add a role to every bot in the server. |
| `,role remove bots <@role>` | Remove a role from every bot. |
| `,temprole <user> <@role> <duration>` | Temporarily assign a role to a member; Wraith removes it automatically when the duration expires. |

### Edit Role Properties

| Command | Description |
| --- | --- |
| `,role edit color <@role> <hex>` | Change a role's color using a hex code (e.g. `#ff5733`). |
| `,role edit name <@role> <name>` | Rename a role. |
| `,role edit hoist <@role> <true/false>` | Toggle whether the role is displayed separately in the member list. |
| `,role edit mentionable <@role> <true/false>` | Toggle whether the role can be @mentioned by everyone. |
| `,role edit icon <@role> <url>` | Set a role icon using an image URL. |
| `,role edit position <@role> <position>` | Move a role to a specific position in the hierarchy. |

Role icons require server Boost Level 2\+.

## Fake Permissions

Grant a role access to Wraith commands without granting real Discord permissions — ideal for trial mods.

| Command | Description |
| --- | --- |
| `,fakeperm add <@role> <permission>` | Grant access to a command/permission node. |
| `,fakeperm remove <@role> <permission>` | Revoke a granted permission. |
| `,fakeperm list <@role>` | List granted permissions. |

Example: `,fakeperm add @Trial Mod ban`

## Custom Punishment Messages

Override the public server message and DM sent to punished users via embed syntax.

### Prefixes

| Prefix | Punishment |
| --- | --- |
| `pban` | Ban |
| `pkick` | Kick |
| `pmute` | Mute |
| `punmute` | Unmute |
| `pwarn` | Warn |
| `pjail` | Jail |
| `punjail` | Unjail |
| `ptempban` | Temporary ban |
| `psoftban` | Softban |

### Setting a Message

<CodeGroup>

```text Public Server Message
,pban message {embed}$v{title: Banned}$v{description: {member} was banned for {reason}}$v{color: #ff0000}
```

```text DM to Punished User
,pban dm {embed}{title: You were banned}{description: You were banned from {guild} for: {reason}}{color: #ff0000}
```

</CodeGroup>

Replace `pban` with any prefix above to customize other punishment types.

## Duration Syntax

| Suffix | Unit |
| --- | --- |
| `s` | Seconds |
| `m` | Minutes |
| `h` | Hours |
| `d` | Days |

Chain units for precision: `1d12h`, `2h30m`, etc.

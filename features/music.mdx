Multi-source playback, vote-to-skip, interactive controls, Last.fm integration.

## Sources

YouTube · YouTube Music · Spotify · SoundCloud · Apple Music

Spotify/Apple Music are resolved via YouTube search.

## Music Commands

| Command | Description |
| --- | --- |
| `,play <song/url>` | Search for a song by name or paste a direct URL to queue it. |
| `,pause` | Pause the current track. |
| `,resume` | Resume a paused track. |
| `,skip` | Cast a vote to skip the current track (majority of listeners required). |
| `,forceskip` | Immediately skip the current track — DJ role or admin only. |
| `,stop` | Stop playback and clear the queue. |
| `,queue` | Display all tracks currently in the queue. |
| `,nowplaying` | Show the now-playing panel with interactive controls. |
| `,volume <1-100>` | Set the playback volume to a value between 1 and 100. |
| `,loop` | Cycle the loop mode: **track → queue → off**. |
| `,shuffle` | Randomly shuffle the tracks remaining in the queue. |
| `,remove <position>` | Remove the track at the specified queue position. |
| `,seek <time>` | Jump to a specific timestamp in the current track (e.g. `1:30` or `90` for 90 seconds). |
| `,skipto <position>` | Skip directly to a specific position in the queue. |
| `,move <from> <to>` | Move a track from one queue position to another. |
| `,replay` | Restart the current track from the beginning. |
| `,disconnect` | Disconnect Wraith from the voice channel and clear the queue. |

## Now Playing Panel

`,nowplaying` posts interactive buttons: ⏮ restart · ⏸/▶ pause/resume · ⏭ skip · 🔁 loop · ⏹ stop.

## Vote to Skip

`,skip` opens a vote. Majority required. DJ role or admins can `,forceskip`.

## Last.fm Setup

```text
,lastfm set <username>
,index
,np
```

`,index` is required after first link. Unlink: `,lastfm unset`.

## Last.fm Commands

| Command | Description |
| --- | --- |
| `,np` | Show the track you are currently or most recently listening to. Requires a linked Last.fm account. |
| `,recent` | Display your most recently scrobbled tracks. |
| `,topartists [period]` | List your top artists for the specified time period. |
| `,topalbums [period]` | List your top albums for the specified time period. |
| `,toptracks [period]` | List your top tracks for the specified time period. |
| `,whoknows <artist>` | Rank server members by their scrobble count for an artist. |
| `,crown <artist>` | Show who currently holds the crown for an artist in this server. |
| `,crowns [@user]` | List all crowns held by you or the mentioned user in this server. |
| `,taste @user` | Compare your music taste with another member's. |
| `,index` | Re-import your scrobble history to keep crown counts up to date. |

## Crowns

Top scrobbler per artist holds that artist's crown. Server-specific. Updated by `,whoknows` and `,np`. Only indexed plays count.

## Period Options

For `,topartists`, `,topalbums`, `,toptracks`. Defaults to overall.

| Period | Description |
| --- | --- |
| `7day` | Last 7 days |
| `1month` | Last 30 days |
| `3month` | Last 3 months |
| `6month` | Last 6 months |
| `12month` | Last 12 months |
| `overall` | All-time history |

## Permissions

Requires **Connect** and **Speak** in the voice channel.

Reactions vote messages into a highlight channel.

## Setup

```text
,starboard channel #starboard
,starboard threshold 5
,starboard emoji ⭐
,starboard
```

## Commands

| Command | Description |
| --- | --- |
| `,starboard` | View the current starboard configuration. |
| `,starboard channel #channel` | Set the channel where starred messages are posted. |
| `,starboard threshold <number>` | Set the minimum number of reactions required (minimum: 1). |
| `,starboard emoji <emoji>` | Set the emoji Wraith watches for reactions. |
| `,starboard reset` | Disable the starboard and clear all settings. |

## Emoji Progression

| Reaction Count | Display Emoji |
| --- | --- |
| 1 – 4 | ⭐ |
| 5 – 9 | 🌟 |
| 10 – 19 | ✨ |
| 20\+ | 💫 |

## Tips

<Accordion title="Reactions can't un-star a message">
  Once a message crosses the threshold and gets posted to the starboard, removing reactions will **not** delete or retract the starboard entry. The post stays even if the reaction count drops back below the threshold.
</Accordion>

<Accordion title="Using custom server emojis">
  You can set a custom emoji from your server as the trigger emoji. Use the emoji directly in the command just as you would in chat — for example:

  ```text
  ,starboard emoji :GoldStar:
  ```

  Make sure Wraith has access to the emoji (i.e., it belongs to a server Wraith is in).
</Accordion>

<Accordion title="Self-reactions don't count">
  A user reacting to their own message with the star emoji does **not** contribute to the reaction count. The threshold must be reached through reactions from other members.
</Accordion>

<Accordion title="Required permissions">
  Wraith needs the following permissions in your starboard channel to function correctly:

  - **Send Messages** — to post the starred message embed.
  - **Embed Links** — to render the embed with the original message content and jump link.

  If either permission is missing, Wraith will be unable to post to the channel.
</Accordion>

<Info>
  If you run `,starboard reset`, the starboard is fully disabled and all settings are cleared. To re-enable it, simply run `,starboard channel #channel` again to set a new destination channel and reconfigure your threshold and emoji.
</Info>

Panel-based support tickets with staff controls and HTML transcripts.

## Setup

1. Create a Discord **category** for ticket channels.
2. Run `,ticket setup` — Wraith prompts for category, support role, log channel, and welcome message.
3. Post the panel:

```text
,ticket panel #support
```

Members click **Open Ticket** to spawn their own private channel.

## Staff Commands

| Command | Description |
| --- | --- |
| `,ticket close` | Close the current ticket, save a transcript, and archive the channel. |
| `,ticket claim` | Assign the ticket to yourself so the team knows who is handling it. |
| `,ticket unclaim` | Release your claim so another staff member can take over. |
| `,ticket add @user` | Grant an additional user access to the ticket channel. |
| `,ticket remove @user` | Remove a user's access from the ticket channel. |
| `,ticket rename <name>` | Rename the ticket channel to something more descriptive. |
| `,ticket transcript` | Manually generate and send an HTML transcript without closing the ticket. |

## Member Limits

Default: 1 open ticket per member. Raise with:

```text
,ticket limit <number>
```

## Transcripts

Closing a ticket auto-generates an HTML transcript to the log channel. Trigger one manually with `,ticket transcript`.

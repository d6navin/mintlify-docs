Custom messages on join, leave, and boost.

## Welcome

```text
,welcome channel #welcome
,welcome message Welcome to {guild.name}, {user.mention}!
,welcome test
```

## Goodbye

Use `{user.name}` — departing members can't be pinged.

```text
,goodbye channel #goodbye
,goodbye message {user.name} has left {guild.name}.
,goodbye test
```

## Boost

```text
,boost channel #boosts
,boost message Thanks for boosting, {user.mention}!
,boost test
```

## Variables

| Variable | Description |
| --- | --- |
| `{user.mention}` | Mentions the user with a clickable ping (`@Username`) |
| `{user.name}` | The user's plain display name without a ping |
| `{user.avatar}` | A URL to the user's current avatar image |
| `{guild.name}` | The name of your server |
| `{guild.count}` | The current total member count of your server |
| `{guild.boost_count}` | The current number of active Nitro boosts on your server |
| `{user.join_position}` | The position at which this user joined (e.g. `42nd member`) |

### Embed Syntax

```text
,welcome message {embed}$v{description: Welcome to {guild.name}, {user.mention}!}$v{color: #2baade}
```

`$v` separates fields. `{color: #hex}` sets the accent.

## Disable

```text
,welcome disable
,goodbye disable
,boost disable
```

Re-enable by setting a channel again.

## Permissions

Wraith needs **Send Messages** in the configured channel.

## Permissions

The default invite requests **Administrator** — the simplest path. Prefer granular? Grant these instead:

| Permission | Used for |
| --- | --- |
| Manage Roles | Autoroles, jail, role commands |
| Manage Channels | VoiceMaster, jail, lockdown |
| Ban Members | Bans, antinuke |
| Kick Members | Kicks |
| Manage Messages | Purge, automod |
| View Audit Log | Antinuke, logging |

Wraith's role must sit **above** any role it manages.

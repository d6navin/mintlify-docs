## Using Wraith

Wraith works with both **prefix commands** and **slash commands**. The default prefix is `,` — so commands look like `,ban`, `,play`, or `,rank`. You can also type `/` in any channel to use slash commands.

You can change the server prefix with `,prefix set <new_prefix>`. Individual members can set their own personal prefix with `,selfprefix <prefix>` without affecting other users.
